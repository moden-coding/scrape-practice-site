# Meeple & Mug: scrape practice site

A small fictional board-game café website for practicing web scraping in
Data Analysis with Python. Plain static HTML and CSS, no JavaScript.

Live at https://moden-coding.github.io/scrape-practice-site/

- `catalog/page-1.html` to `catalog/page-12.html`: the game library, 10 games per page
- `catalog/game-<slug>.html`: one detail page per game (120)
- `catalog/about.html`, `events.html`, `menu.html`, `page-turners-book-club.html`: other café pages

All names, prices, and descriptions are made up.
